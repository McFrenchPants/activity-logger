Visual system · v0

Two voices: your words, and what the app understood.

Material 3 structure with a quiet, paper-and-ink palette. The one signature move: anything the user actually said is set in serif italic, in quotes — interpretations, labels and controls are sans. Evidence is never styled like app output, so the original phrase is always recognisable at a glance.

State vocabulary

Saved
Captured, interpreted, persisted. The quiet default — rows show no tag at all.
In progress
ActivityState IN_PROGRESS (“I’m mowing the lawn”).
Needs review
Interpretation unsafe. Words saved, no activity guessed.
Not categorized yet
Captured, not interpreted (AI unavailable). Dashed outline = incomplete.
Queued
On the watch, waiting for the phone.
Couldn't capture
Nothing saved. Always paired with a retry.

Every state = distinct icon shape + text label + colour. Remove the colour and it still reads.

Shape & spacing

Cards 16dp radius · fields/rows 12dp · chips 8dp · buttons full pill · capture button 112dp (96/88 when a feedback card is shown) · 16dp screen gutter · 48dp minimum target · list rows min 72dp.

Not in this system

No checkboxes, badges with unread counts, priority flags, due-date pickers, streak or score widgets, kanban columns, or calendar grids (UX_SPEC §15). No sparkle/“AI” iconography — interpretation is presented as a plain fact with its evidence beside it.
